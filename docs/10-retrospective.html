1 プロジェクト振り返り

企画・設計段階の振り返り 必須
マーケットリサーチ、ペルソナ設計、情報設計について

企画段階では、inimuの強みである日本素材、浅草立地、香り体験の価値を整理し、来店前に「選ぶ理由」が伝わる構成を意識しました。マーケットリサーチでは、体験型フレグランス店や観光土産店との違いを比較し、30代女性・感度層、観光客、2名来店層に向けた導線設計を検討しました。情報設計では、TOP、WORKSHOP、PRODUCTS、STORY、VISIT、RESERVEなどのページ役割を分け、予約や商品理解につながる流れを組み立てました。

デザイン段階の振り返り 必須
デザインガイドライン、ワイヤーフレーム、Figma作業について

デザイン段階では、Figmaを使ってファーストビューやワイヤーフレームを検討し、浅草らしさ、香りの繊細さ、ブランド背景が伝わる見せ方を意識しました。単にきれいに見せるだけでなく、初めて訪れるユーザーが「何ができるサイトか」「どこから予約できるか」を迷わず理解できる構成にすることを重視しました。

フロントエンド実装の振り返り 必須
HTML/CSS/JavaScript の実装について

フロントエンド実装では、HTML / CSS / JavaScriptを使い、複数ページの構成、ナビゲーション、商品カード、予約ページ、問い合わせページを制作しました。レスポンシブ対応や視認性を意識しながら、画像やCTAの配置を調整しました。JavaScriptでは、予約日選択、時間帯表示、確認画面更新など、ユーザー操作に応じて画面が変化する処理を実装できたことが学びになりました。

バックエンド実装の振り返り 必須
Java/Spring Boot の実装について

バックエンド実装では、Java / Spring Bootを使い、予約情報や問い合わせ情報を受け取るAPIの仕組みを学びました。フロントエンドのフォームから送信されたデータが、Controller、Service、Mapper、データベースへ流れる構造を理解することで、画面制作だけでなくWebアプリケーション全体のつながりを意識できるようになりました。

全体を通しての学び 必須
42日間のプロジェクト全体を通して学んだこと

全体を通して、企画、情報設計、デザイン、実装、テスト、ドキュメント作成までを一連の流れとして経験できました。前職で培った顧客要望の整理力や制作進行の経験は、Web制作でも「何を誰に伝えるか」を整理する場面で活かせると感じました。一方で、JavaScriptやバックエンド実装はまだ基礎理解を深める余地があるため、今後も小さな機能を自分で作りながら実践力を高めていきたいです。

2 技術記事

技術記事タイトル 必須

JavaScriptで予約フォームをAPIにつなぐ実装手順

記事本文 必須
上記の構成に沿って記事本文を記載。コードブロックを含めてください。

今回の予約ページでは、ユーザーが日付・時間帯・人数・氏名などを入力し、「この内容で予約する」ボタンを押すと、JavaScriptで入力内容をまとめてAPIへ送信する流れを実装しました。

実装で意識したのは、送信前に必須項目を確認すること、送信中はボタン表示を切り替えて二重送信を防ぐこと、APIからの結果に応じて完了画面またはエラーメッセージを表示することです。

const payload = {
  slotId: selectedSlotId,
  name: name,
  nameKana: kana,
  email: email,
  phone: tel,
  numPeople: parseInt(document.getElementById('people-select').value)
};

const res = await fetch('/api/v1/reservations', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(payload)
});

この実装を通して、フォーム入力値をJavaScriptで取得し、JSON形式にまとめてサーバーへ送る基本的な流れを理解できました。また、フロントエンド側だけで完結させるのではなく、バックエンドのAPI設計やエラー時の返却内容も意識する必要があることを学びました。
